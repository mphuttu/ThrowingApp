Technical information

ThrowingApp is implemented as a native Windows application using MFC and the Windows SDK. The calculation model uses a simplified gravity-based projectile equation and stores throw data in the document model.

Requirements

  • Windows 10 or Windows 11 x64
  • Microsoft Visual C++ runtime dependencies
  • Access to the required MFC support libraries

Architecture notes

The application keeps trajectory logic in the document and view layer, with dialog-based parameter entry for configuration and calculations. This separation keeps the interface simple while allowing future extension.
