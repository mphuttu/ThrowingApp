Configuration and settings

Use the options dialog to set the parameters used by the calculation engine. Each change updates the active trajectory and, when valid, adds a result to the results list.

SettingPurposeNotes
Launch heightSets the release height above the ground.Use metric values such as meters.
Initial velocityControls the projected speed at launch.Positive values only.
Throw angleAdjusts the elevation of the release.Use realistic values below 90?.
ScaleChanges the plot scaling on the axis.Useful when comparing short and long throws.
ColorAssociates each result with a visible chart color.Improves comparison across multiple attempts.
Warning: Invalid or empty input values are rejected. Values must be positive and consistent with the supported trajectory model.
