Product overview

ThrowingApp is a compact Windows MFC application designed to evaluate projectile motion. It supports quick parameter experiments for throws that begin above the ground and travel under gravity.

The program is intended for practical comparison work, such as evaluating the impact of launch angle and initial speed on range, rather than for a full biomechanical analysis system.

Key features

  • Interactive analysis of launch height, initial velocity, and release angle.
  • Graphical flight path plotted within the application view.
  • Results table for launch height, velocity, angle, and distance.
  • Color-coded throw records for clear comparison between attempts.
  • Angle and velocity estimation utilities for optimization workflows.
  • Built-in help system and Windows installer packaging.
Audience: Suitable for sports analysis, technical comparison, and engineering-style experimentation.
