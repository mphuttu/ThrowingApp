Getting started

Installation

  1. Download and run the installer package for the current ThrowingApp release.
  2. Accept the installation prompts and choose the installation folder.
  3. Complete the installation and launch the application from the Start menu or desktop shortcut.

First launch

On first launch, the application opens with a default throw scenario. The graph shows a projected path and the results dialog summarizes the current data.

Quick start

  1. Open the Options dialog to edit launch height, velocity, and angle.
  2. Review the plotted trajectory in the main view.
  3. Use the estimate tools when an angle or velocity must be derived from a target range.
  4. Compare multiple attempts in the results dialog.
Tip: A typical workflow is to set known inputs, calculate the range, and then tune the parameters until the projected results match the target values.
