How to Use Throwing App



To use the Throwing App, follow these steps:

  1. Open the 'Options' menu item 'Set parameters'
  2. Set the initial velocity (m/s2), throw angle (in degrees), and initial throw height (m, meaning at what height the object leaves).
  3. Set the scaling factors for X and Y coordinates (pixels/m) or leave the default values.
  4. Choose a color for a throw.
  5. Press OK and the throw is drawn in the client area of the app.


The Result

  1. The graphical arc is drawn on the client area.
  2. The details of the throw are found on the Results window.
  3. You can add more throws repeating the 'Set parameters and add throw' procedure.
  4. You can save the results and open the results later.
  5. You can print the results on the printer. When you print a graphic area on a printer, the image may not fit in the print area, in which case the scaling must be changed and you should select the horizontal setting for the print settings.
