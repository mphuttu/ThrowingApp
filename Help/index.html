Welcome to ThrowingApp

ThrowingApp makes projectile motion calculations easy to review and compare in a desktop Windows workflow. Use it to model launch conditions, inspect the trajectory, and evaluate the resulting throw distance.

This help file includes installation guidance, configuration tips, feature details, troubleshooting advice, and release notes.

Audience Athletes, coaches, and technical users evaluating throwing performance.
Core inputs Launch height, initial velocity, and throw angle.
Primary output Flight path and total throw distance.

What this application does

ThrowingApp calculates a projectile path using a standard gravitational model. It applies the selected start height, initial speed, and release angle to estimate a flight curve and the projected throw distance.

Users can compare multiple throw attempts and review the calculated values side by side in the results dialog.

Tip: Start with realistic values for launch height and velocity before comparing different angles.
