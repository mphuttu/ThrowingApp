Feature reference

Trajectory plot

The main view draws the flight path for each configured throw. The plot is scaled to the data and shows the active projectile path in the selected color.

Results dialog

The results window summarizes each entry using the launch height, initial velocity, angle, and projected flight distance. It is ideal for comparing multiple attempts.

Angle estimation

The angle estimation dialog solves for a release angle when the flight distance, launch height, and initial speed are known. This is useful for optimization and comparison workflows.

Velocity estimation

The initial velocity estimator identifies the speed required for the chosen distance, angle, and launch height. It is useful for target-setting and benchmarking.

Example: Compare a 1.75 m release height with a 23.56 m target distance and adjust the angle or speed until the estimated result matches the desired range.
